🏗️ MODELO DE VON NEUMANN Y HARVARD

Arquitecturas de diseño para computadoras. El modelo de Von Neumann emplea una única memoria para almacenar tanto datos como instrucciones del programa, lo que implica que la CPU accede a ellas por el mismo canal. La arquitectura Harvard utiliza memorias separadas para instrucciones y datos, permitiendo accesos simultáneos y frecuentemente usada en microcontroladores.

Ejemplo: En el modelo Von Neumann, si la CPU necesita leer una instrucción y un dato, debe hacerlo uno por uno a través del mismo canal; en Harvard (utilizada en microcontroladores como Arduino), la CPU puede leer la instrucción y el dato al mismo tiempo usando canales separados.

⚙️ SISTEMAS OPERATIVOS

Software principal que administra y coordina los recursos de hardware del computador (procesador, memoria, almacenamiento y periféricos). Proporciona servicios para la ejecución de aplicaciones, gestión de procesos, planificación, seguridad y manejo de archivos.

Ejemplo: Windows o macOS administrando la memoria RAM y el procesador cuando abres al mismo tiempo un navegador web y un reproductor de música; el sistema operativo asigna tiempo de CPU y memoria a cada aplicación y evita conflictos.

🔢 SISTEMAS DE NUMERACIÓN Y CONVERSIONES (BINARIO, OCTAL Y HEXADECIMAL)

Sistemas de representación numérica basados en distintas bases: binario (base 2), octal (base 8) y hexadecimal (base 16). Son usados para representar valores en electrónica digital y programación de bajo nivel.

Ejemplo: El número decimal 10 se escribe como 1010 en el sistema binario y como A en el sistema hexadecimal.

➕ ARITMÉTICA BINARIA

Reglas y operaciones matemáticas (suma, resta, multiplicación y división) realizadas utilizando únicamente los dígitos 0 y 1. Incluye el manejo de acarreo y operaciones a nivel de bit que son fundamentales para los circuitos aritméticos del procesador.

Ejemplo: Al sumar los números binarios 1 y 1, el resultado es 0 y se lleva un acarreo de 1 a la siguiente posición, formando el número binario 10.

🔶 ÁLGEBRA DE BOOLE

Estructura matemática para la manipulación y simplificación de variables lógicas que solo poseen dos estados posibles (Verdadero/1 o Falso/0). Se usan operadores como AND, OR y NOT para modelar circuitos digitales y condiciones lógicas.

Ejemplo: Un sistema de alarma que solo se activa (resultado 1) si la puerta está abierta (entrada A = 1) Y el sensor de movimiento detecta presencia (entrada B = 1); la salida es A AND B.
