🏗️ Modelo de Von Neumann y Harvard

Arquitecturas de diseño para computadoras. El modelo de Von Neumann emplea una única memoria para almacenar tanto datos como instrucciones del programa, mientras que la arquitectura Harvard utiliza memorias y buses físicamente independientes para datos e instrucciones. Esta última mejora el rendimiento al permitir acceso simultáneo a datos e instrucciones, siendo especialmente utilizada en procesadores embebidos y sistemas de tiempo real.

⚙️ Sistemas Operativos

Software principal que administra y coordina los recursos de hardware del computador (procesador, memoria, almacenamiento y periféricos), sirviendo como plataforma de ejecución para las aplicaciones de usuario. El sistema operativo proporciona una interfaz amigable entre el usuario y el hardware, gestionando tareas como la asignación de recursos, la seguridad, la multitarea y el manejo de dispositivos periféricos.

🔢 Sistemas de Numeración y Conversiones (Binario, Octal y Hexadecimal)

Sistemas de representación numérica basados en distintas bases. El sistema binario (base 2) es utilizado por los circuitos del procesador, mientras que el octal (base 8) y hexadecimal (base 16) facilitan la representación simplificada de largas cadenas binarias. Estos sistemas son fundamentales para comprender cómo se almacena y procesa la información en las computadoras, permitiendo conversiones eficientes entre diferentes notaciones numéricas.

➕ Aritmética Binaria

Conjunto de reglas y operaciones matemáticas elementales (suma, resta, multiplicación y división) realizadas de forma directa utilizando únicamente los dígitos 0 y 1. Las operaciones binarias son la base de todas las operaciones realizadas en los circuitos lógicos de un procesador, permitiendo que la máquina realice cálculos complejos mediante combinaciones de operaciones simples entre bits.

🔶 Álgebra de Boole

Estructura matemática para la manipulación y simplificación de variables lógicas que solo poseen dos estados posibles (Verdadero/1 o Falso/0), mediante la aplicación de operadores como AND, OR y NOT. El álgebra booleana es esencial para el diseño de circuitos digitales y la implementación de lógica en los sistemas computacionales, permitiendo simplificar expresiones complejas para optimizar el diseño del hardware.
