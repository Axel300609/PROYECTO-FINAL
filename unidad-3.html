📚 LENGUAJES Y PARADIGMAS DE PROGRAMACIÓN

Los lenguajes son conjuntos de símbolos y reglas sintácticas para escribir instrucciones; los paradigmas representan los enfoques o filosofías que determinan cómo se organiza y piensa la solución (imperativo, declarativo, orientado a objetos, funcional, etc.).

Ejemplo: Python puede utilizarse bajo el paradigma imperativo para ejecutar instrucciones paso a paso, o bajo estilos funcionales con funciones puras y composición.

🐍 INTRODUCCIÓN A LA PROGRAMACIÓN EN PYTHON

Aplicación de la sintaxis, tipos de datos e instrucciones elementales del lenguaje Python para la elaboración y ejecución de programas informáticos. Python es un lenguaje versátil y de fácil lectura.

Ejemplo:
nombre = "Axel"
print("Hola, " + nombre)
Este código crea una variable de texto y luego imprime un saludo por pantalla, mostrando: Hola, Axel

⚙️ OPERADORES ALGEBRAICOS, RELACIONALES Y LÓGICOS

Símbolos diseñados para ejecutar operaciones sobre variables: aritméticos para cálculos, relacionales para comparaciones y lógicos para combinar condiciones.

Ejemplos:
• Algebraico: total = precio * cantidad
• Relacional: es_mayor = (edad >= 18)
• Lógico: acceso = (usuario_correcto and clave_correcta)

🔀 ESTRUCTURAS DE CONTROL CONDICIONALES

Instrucciones que evalúan condiciones para determinar qué bloque de código ejecutar. Permiten que el programa tome decisiones basadas en los datos.

Ejemplo:
if nota >= 7:
    print("APROBADO")
else:
    print("REPROBADO")
Este ejemplo verifica si la nota es mayor o igual a 7 y muestra el resultado correspondiente.

🔁 ESTRUCTURAS DE CONTROL REPETITIVAS

Bloques de código que repiten acciones mientras se cumpla una condición o por un número determinado de veces. Permiten automatizar tareas repetitivas.

Ejemplo:
for i in range(1, 4):
    print(i)
Este código imprime los números 1, 2 y 3 utilizando un bucle for que itera tres veces.
