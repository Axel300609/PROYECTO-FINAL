📚 Lenguajes y Paradigmas de Programación

Los lenguajes son conjuntos de símbolos y reglas sintácticas para escribir instrucciones; los paradigmas representan los enfoques o filosofías teóricas que determinan cómo se organiza la estructura y el comportamiento del software. Existen paradigmas como programación imperativa (enfocada en cómo hacer algo), programación declarativa (enfocada en qué hacer), programación orientada a objetos (basada en objetos y clases), y programación funcional (basada en funciones matemáticas). Cada paradigma tiene fortalezas específicas para diferentes tipos de problemas.

🐍 Introducción a la Programación en Python

Aplicación de la sintaxis, tipos de datos e instrucciones elementales del lenguaje Python para la elaboración y ejecución de programas informáticos. Python es un lenguaje versátil y accesible que destaca por su sintaxis clara y legible. Incluye conceptos como variables, tipos de datos primitivos (enteros, flotantes, cadenas, booleanos), asignación de valores, entrada/salida básica, y estructuras de control fundamentales. Python es ideal para aprender conceptos de programación debido a su curva de aprendizaje suave.

⚡ Operadores Algebraicos, Relacionales y Lógicos

Símbolos diseñados para ejecutar operaciones específicas sobre variables. Operadores Algebraicos realizan operaciones aritméticas básicas (suma +, resta -, multiplicación *, división /, módulo %, potencia **). Operadores Relacionales validan relaciones de orden o equivalencia entre valores (igual ==, diferente !=, mayor >, menor <, mayor o igual >=, menor o igual <=). Operadores Lógicos combinan expresiones verdaderas o falsas mediante reglas booleanas (AND, OR, NOT). Estos operadores son fundamentales para construir expresiones complejas y tomar decisiones en programas.

🔀 Estructuras de Control Condicionales

Instrucciones que evalúan una condición lógica para determinar qué bloque de código ejecutar. Las estructuras condicionales incluyen la sentencia if (si la condición es verdadera, ejecuta el bloque), if-else (ejecuta un bloque u otro según la condición), if-elif-else (evalúa múltiples condiciones en secuencia), y operador ternario (sintaxis compacta para condiciones simples). Estas estructuras permiten que los programas tomen decisiones y ejecuten diferentes caminos según las circunstancias, siendo esenciales para crear lógica flexible y adaptativa.

🔁 Estructuras de Control Repetitivas

Bloques de código encargados de iterar una serie de instrucciones un número determinado de veces o mientras se mantenga cierta condición. Las estructuras repetitivas incluyen el bucle for (itera un número específico de veces o sobre elementos de una colección), el bucle while (itera mientras se cumpla una condición), y sentencias de control de flujo como break (termina el bucle) y continue (salta a la siguiente iteración). Estas estructuras son vitales para automatizar tareas repetitivas, procesar colecciones de datos y crear algoritmos eficientes que evitan código redundante.
