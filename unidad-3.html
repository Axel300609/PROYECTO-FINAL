📚 Lenguajes y Paradigmas de Programación

Los lenguajes son conjuntos de símbolos y reglas sintácticas para escribir instrucciones; los paradigmas representan los enfoques o filosofías teóricas que determinan cómo se organiza y estructura el código.

Ejemplo: Python puede utilizarse bajo el paradigma imperativo para ejecutar instrucciones paso a paso (especificando "cómo" hacer algo), o bajo el paradigma orientado a objetos utilizando clases y objetos (definiendo estructuras y comportamientos reutilizables).

🐍 Introducción a la Programación en Python

Aplicación de la sintaxis, tipos de datos e instrucciones elementales del lenguaje Python para la elaboración y ejecución de programas informáticos. Python es un lenguaje versátil, legible y con una sintaxis intuitiva.

Ejemplo:
nombre = "Axel"
print("Hola, " + nombre)
Este código crea una variable de texto y luego imprime un saludo por pantalla, mostrando: Hola, Axel

⚡ Operadores Algebraicos, Relacionales y Lógicos

Símbolos diseñados para ejecutar operaciones específicas sobre variables. Los operadores algebraicos realizan operaciones aritméticas, los relacionales comparan valores y los lógicos combinan condiciones.

Ejemplos:
• Algebraico: total = precio * cantidad
• Relacional: es_mayor = (edad >= 18)
• Lógico: acceso = (usuario_correcto and clave_correcta)

🔀 Estructuras de Control Condicionales

Instrucciones que evalúan una condición lógica para determinar qué bloque de código ejecutar. Permiten que el programa tome decisiones basadas en los datos.

Ejemplo:
if nota >= 7:
    print("Aprobado")
else:
    print("Reprobado")
Este código verifica si la nota es mayor o igual a 7 para mostrar si el estudiante aprobó o reprobó.

🔁 Estructuras de Control Repetitivas

Bloques de código encargados de iterar una serie de instrucciones un número determinado de veces o mientras se mantenga cierta condición. Permiten automatizar tareas repetitivas.

Ejemplo:
for i in range(1, 4):
    print(i)
Este código imprime los números 1, 2 y 3 utilizando un bucle for que itera tres veces.
