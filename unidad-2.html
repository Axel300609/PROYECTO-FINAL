🔁 ALGORITMOS Y SUS CARACTERÍSTICAS

Un algoritmo es una secuencia finita de pasos bien definidos para resolver un problema o realizar una tarea específica. Debe ser claro, finito y efectivo.

Ejemplo: La secuencia exacta para calcular un promedio: pedir las notas, sumarlas todas, dividirlas entre la cantidad de notas y mostrar el resultado final.

🔀 DIAGRAMAS DE FLUJO

Representación gráfica de un algoritmo usando símbolos (óvalo para inicio/fin, rectángulo para procesos, rombo para decisiones, flechas para flujo).

Ejemplo: Un diagrama con un rombo que pregunta "¿EDAD ≥ 18?": si SÍ → flecha a rectángulo "PERMITIR ENTRADA"; si NO → flecha a rectángulo "DENEGAR ENTRADA".

📝 PSEUDOCÓDIGO

Forma intermedia entre lenguaje natural y lenguaje de programación que usa instrucciones ordenadas y fáciles de convertir a código.

Ejemplo: SI calificacion >= 7 ENTONCES mostrar "APROBADO" SINO mostrar "REPROBADO".

🧩 MODELADO DE PROBLEMAS

Proceso de descomponer y estructurar un problema para diseñar soluciones: identificar entradas, salidas, reglas y pasos necesarios para resolverlo.

Ejemplo: Al modelar un cajero automático: pedir tarjeta y clave → verificar clave → si coincide, pedir monto y entregar dinero; si no coincide, mostrar error y solicitar reintento.
